# 🍵 BuildLab

> Welcome to **BuildLab** —  Dawnei's little corner for tinkering with Java and Spring Boot. A curious techbaby's corner for brewing backend experiments, wandering through unfamiliar concepts, occasionally leaving a few digital ruins, and learning the craft one cup of tea at a time.

---

### 🪴 What's Happening Here?

Exploring software development from the ground up. Not one massive application, but a growing collection of experiments, discoveries and implementations — understanding how things work, how they connect, and eventually how to build complete applications.


### 🎒 What's on the kit?

- **Language:** Java
- **Framework:** Spring Boot
- **Build Tool:** Maven
- **Version Control:** Git & GitHub

### 🏚️ A Little Note for Travelers

This is an evolving workspace. You might find Codeez exploring individual concepts, unfinished ideas, interesting bugs and lessons picked up along the way.

Feel free to look around!


### ☕ Setting Up your space

Want to explore the lab locally?

1. **Take tools**
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. **Step inside:**
   ```bash
   cd buildlab
   ```

3. **Fire up the lab:**
   ```bash
   ./mvnw spring-boot:run
   ```

   On Windows PowerShell, use:
   ```powershell
   .\mvnw.cmd spring-boot:run
   ```
